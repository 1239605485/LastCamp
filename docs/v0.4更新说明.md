# v0.4 更新与验证 · 2026-10-26

## 本轮需求

处理用户安卓截图反馈：物品白边、人物/僵尸行走转圈、按键过小、场景无法缩放、按钮大小位置自定义、图标主操作、持枪与枪口、野外建筑过密、植物与果树采集、四项生存状态UI。平台继续仅安卓64位。

## 根因和实现

Mini 玩家源 Animation 的 run_melee_down 为4/5/6/7，up为8/9/10/11，right为12/13/14/15，left为16/17/18/19。旧代码固定方向列、变换动画行，导致步伐变成转向。actor_pose.gd按原始帧表取帧；僵尸按方向行/步伐列读取。NPC和僵尸用实际位移决定行走，站立不持续踏步。持枪行走叠加瞄准上身，搜寻/采集使用源work姿态。

弹道之前从玩家脚下发出。枪身和弹道现在共用手部/枪口锚点，按枪长计算。弹道先裁剪到障碍距离，再选择命中对象，避免墙角处视线斜穿过去而伤害直线弹道后方目标。测试实际复现旧错误：营地玩家(200,272)、右向手枪、敌人(260,283)。

白边是源图中不透明像素。icon_image.gd只清理透明外缘邻接的近白像素，保留内部白色；小绷带等被清理后过薄时将轮廓改成灰色，避免只剩一条线。树木源sheet有站立和倒下两帧，改为只取站立半幅并按实际树干像素锚定，苹果在同一树冠内绘制。

HUD主操作均图标化，菜单保留说明文字。默认72px/开火80px，设置支持56–112px单按钮、100–190px摇杆直径，放大时图标也同步变大。布局编辑支持拖动、逐个缩放、恢复默认；user://controls.cfg独立保存布局与辅助瞄准/左右手选项。双指缩放仅使用未被控件或摇杆占用的触点，0.65–1.8倍；缩小时扩大地面绘制区域。四项状态条有不同颜色、图标及数值。

地图v4分散聚落中心、集中摆放建筑；仅5处独立野外建筑。v3和更早地图保留生成逻辑，旧存档不重排。植物按种子与块生成，缓存有上限；果树有树干碰撞。Forage按世界分钟保存下次可采时间；完整动作后校验距离、可达与负重，才一次提交水果和冷却。移动/受击取消、背包满、读档、再次采集均有检查。果实是独立物品定义及图标，能恢复饱食与少量水分，没有添加未经请求的复杂腐败或疾病系统。

## Rogue Survivor alpha 10.1 源码检查

本地压缩包已读取：

- WRogue/Engine/Rules.cs：FoodPoints阈值、饥饿与饥荒分开判定，StaminaPoints与行动门槛，以及食物新鲜度按游戏回合记录。
- WRogue/Engine/MapGenerator.cs：Generate(seed)与地块生成辅助函数。
- WRogue/Gameplay/Generators/BaseTownGenerator.cs、StdTownGenerator.cs：街区、商店、公园的分层生成及概率配置。
- WRogue/Gameplay/Generators/BaseMapGenerator.cs：角色初始食物/体力与物品工厂。

适用借鉴是种子生成与地点内容分离、食物和体力作为独立状态、资源恢复使用游戏时间。这些思想应用于本工程Godot实时系统；没有复制整套C#引擎或资源。睡眠、精神状态、食物腐败与其全部NPC行为尚未加入，不把源码中存在的功能当作本工程已完成。
