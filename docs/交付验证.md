# v0.1 第一轮交付记录 · 2026-10-26

## 验证层级

- Godot 4.7.2编辑器导入完成，无脚本解析错误。
- 数据回归：34项通过。覆盖容量失败守恒、装配与拆扩容、全掉落与多遗物、家具唯一性、统一尸潮与暂停、损坏备份恢复、人员工作、死亡恢复防守、有效生成边界、战后结算、结构和所有权校验。
- 场景交互：19项通过。覆盖桌面按钮操作、不可靠近搜刮、受击中断、实际取物、墙体碰撞/视线、招募与单随行、跨区、面板暂停、双摇杆第三指/跨GUI释放、重复跨区不重开尸潮、第一夜离屏推进。
- 已启动实际桌面渲染，检查营地、建筑室内、背包与夜间截图。当前显卡使用Godot自动回退的ANGLE/D3D11兼容路径，存在OpenGL3.3驱动提示，未将其标为安卓问题。
- 当前仅保留Android arm64调试签名APK；已按用户要求移除Windows导出配置与电脑试玩包，后续只生成安卓64位。构建日志在builds。
- 未连接Android设备：安装启动、实际多指输入、刘海长屏、后台恢复、持续温升与电量尚未实机验证。

2. 尸潮生成点不能落在移动边界外，新增测试先失败再修复。
3. 招募不能突破最多1名随行，新增测试先失败再修复。

测试用存档改为独立子目录。开发初期产生的默认演示存档已移入用户目录development-snapshots留档，不作为第一次试玩的开局。

## 性能与内容边界

Orven美术接入阶段做过30/60/100敌人的Windows短时梯度观测，约31.7/28.7/21.8 FPS，详见builds/desktop-benchmark.json。显卡是AMD R7 M340的ANGLE路径，观测窗口很短，不能作为安卓帧率或最终性能结论。100敌人档未达到30 FPS；本版实际教学波次15只，不声称已经支持100只稳定战斗。后续Kenney/CobraLad美术补充尚未重新进行同一梯度对比。

本交付是第一轮可玩原型，未把整份设计文档的全部验收场景标记为通过。主要缺口：完整格子背包/拆分丢弃、复杂路线、长期七天供给平衡、UI深度自定义及安卓实机验证。详见README。

## 素材选择

当前主视觉Orven免费版仅限非商业测试。Kenney补植被与UI，CobraLad补车辆与碎石，保持16px源像素和2倍最近邻；未引入付费资源或CraftPix高清矢量建筑。许可、署名和筛选原因分别在assets/ASSET-SOURCES.md、docs/素材筛选.md。
