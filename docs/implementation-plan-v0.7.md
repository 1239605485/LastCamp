# 0.7 多日生存增量计划

依据：附带开发文档第16.2节和工程交接。继续现有Godot二维工程。

1. 新增 `resource_cycle.gd`：岸边取脏水、在普通民居/诊所的室内料理点煮沸、用有限净水片处理水、制作绷带和雨水收集器。每个动作在完成时重验位置/库存/容量，一次性交换；实际行动仍通过game现有可中断计时。
2. 收集器使用地区ID与全局实体ID，储水上限8份，降雨按统一世界时间计算，未加载地区也只结算一次；不会因现实时间或读档补水。
3. 沿用schema6，增加可选且严格校验的resource_cycle字段；旧档缺字段时惰性初始化，不改地图和物品。
4. 参考All Alone的Gun.cs，实现有上限的连续射击散布与停火恢复；参考BoardedWindow.cs，敌人贴近门窗时不允许封堵。不移植三维脚本、波次和买枪机制。
5. 新增Godot行为测试：容量失败无扣材、取消不扣材、来源距离、雨水上下限、存读档/跨区、旧档可读、七日水食供给路径、射击散布恢复和窗口威胁。
6. 接入原生生存菜单、背包图标与世界收集器提示；补跨平台检查脚本、更新交付说明。

边界：本次不声称完成第二阶段全部内容，工具耐久、净水容器逐瓶建模、工具替代经济和安卓真机压力测试仍需后续。当前环境没有Godot/Android SDK；网络获取失败时只能交付待引擎验证源码，并明确列出未执行检查。
