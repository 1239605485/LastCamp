# 2026-10-26 素材筛选与接入记录

目标：文档要求的Mini DAYZ式小人物，16px源图格、世界2倍最近邻绘制，俯视略带立面、低饱和现代废土。保留Orven主角与僵尸，补环境和UI，避免不同画风角色混用。

| 网站/具体包 | 核验结果 | 本版决定 |
|---|---|---|
| itch.io / Orven Wasteland Essentials Free | 已下载，原始Read me限制非商业、禁止素材独立转售分发 | 保留角色、僵尸、营地道具与地块；商用需取得Premium许可 |
| Kenney / Tiny Town | 16×16、CC0，建筑偏明亮童话风 | 仅接入树木，绘制时压低亮度，不使用其角色或童话建筑 |
| Kenney / UI Pack Pixel Adventure | CC0，含像素边框/面板 | 接入深色九宫格面板和按钮，统一青灰调色 |
| OpenGameArt / CobraLad Post-apocalyptic 16x16 tileset | 16×16，CC-BY-SA 3.0；现代废土车辆、碎石等 | 接入少量车辆、桶与碎石，保留原图与许可、署名，不替换角色 |
| OpenGameArt / Wasteland Tileset (mauriku) | CC-BY 3.0，矢量/侧面表现，与现有视角不同 | 不接入 |
| CraftPix / Free Zombie TDS Buildings and Furniture | 161 PNG部件，页面标为vector，高清正俯视 | 不接入，避免缩成像素后细节与透视冲突 |
| CraftPix / Free Basic Pixel Art UI for RPG | 页面明确偏fantasy/medieval，包含魔法、剑盾等UI | 暂不接入，与现代生存题材不符 |

itch.io分类页返回403，改为具体作者页与可访问的包页核验，未声称穷尽所有素材。付费文件与需登录下载的资源未访问，未创建账号或代付款。使用免费/开源包不等于将整个工程自动视为可商用；当前Orven免费版仍是商业发布前需要解决的一项。
