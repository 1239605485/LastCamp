# v0.2 · Mini风格个人自用扩展

仅交付Android arm64，包名仍为org.lastcamp.survival，版本号0.2.0 / versionCode 2，沿用本机调试签名，方便覆盖测试。

## 本轮实际改变

- 16种枪械：Glock17、AKM、PM、Colt1911、Magnum、MP5K、UMP45、PP19野牛、AK74、M4、AUG、SKS、Mosin、SVD、Remington870、IZH43。
- 14种配件、5类槽位：9mm/步枪消音器、制退器、补偿器、扩容/快速/弹鼓、红点/2倍/4倍镜、垂直/斜角握把、枪灯、稳定枪托。兼容接口、容量、噪声、散布、瞄准速度、换弹、射程或照明实际生效。同槽不叠加，拆弹鼓会退回超容量子弹，空间不足则阻止。
- 弹药分9mm、9×18、.45、.357、5.45、5.56、7.62×39、7.62×54R、12号；不能跨口径换弹。霰弹枪一次消耗一发霰弹并结算多个弹丸；枪械的伤害、射速、射程和换弹分别配置。
- 使用用户Mini包的地形、树木、建筑外观/室内、人物、僵尸、车辆、枪械与配件图标；摄像机跟随玩家，视觉比例改为Mini式原60px地块与小人物。
- 安卓左摇杆移动、右摇杆瞄准、独立开火；停步持续瞄准收紧准星，移动扩大散布。开火与第三指使用物品各自处理触摸ID。
- 10240×8960连续探索区，8×8街区、129处可进入建筑；道路贯通、河流与桥接通路、不同聚落。附近绘制/碰撞/敌人AI，远处营地仍用权威时钟结算。
- 大地图可以缩放、拖动、定位玩家和点按设定目标；保存探索街区、遗物位置与目标点，不提供传送。
- 新增营地东侧军械补给箱，提供新枪/配件/弹药用于自用测试；野外地点也生成相应物资。原有存档第一次载入时补齐扩展，content_version阻止重复发放。军械箱不影响营地仓库所有权。
- 背包改为图标格，配件页左右选择枪械/查看装配、实际性能和弹种；同型号多把枪按实例装备。

## 操作说明

到营地东侧“军械补给箱”旁互动，逐项取出所需枪、配件及对应弹药。背包点击枪械装备；“副武器/主武器”按钮轮换携带的该类枪。“枪械配件”页先选枪，再安装兼容配件。装备太多会超重，留备用枪在箱子中。

向东进入探索区后可继续沿路走到各街区；仅在起点西侧道路口回营。点击地图、放大并定位玩家，再点按设置目标，HUD显示目标距离与方向。

## 验证边界

本轮回归共88项通过：原数据34、原场景19、装备/地图/真实旧档升级24、新场景与多指控制11。独立检查发现的“第三指无法开火”和“营地远处攻击者被冻结”已先用测试复现，再修复。另补充同型号枪实例选择、存入箱子后移除当前装备显示、拒绝给已存入箱子的枪换弹。日志见builds下*-v02.log。

代码检查、自动回归、桌面编辑器渲染仅用于开发验证，不生成电脑端程序。Android安装、实际多指手感、长时间运行、温升与大地图性能仍需实机验证。大地图是新建规则，不是完整原版Mini DAYZ；长期经济仍处于原型调参阶段。Mini美术按用户个人自用要求接入，未公开发布。
