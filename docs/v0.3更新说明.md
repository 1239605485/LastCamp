# v0.3 更新与验证

本轮依据用户 UI 参考、建筑穿墙截图和触摸滑轨反馈更新；设计文档保留为产品依据，源码和网页内容只作为参考材料。

## 根因与处理

建筑原先使用统一外框，与 Mini 室内墙及楼梯图像不对应。本版提取原场景的碰撞多边形、室内区域和贴图偏移，用相同变换绘制和碰撞。提取工具曾错误跨过空节点，导致偏移读为零，已修正解析并增加底部对齐回归。枪店没有原始门节点，已按图中实际门洞设置门中心，验证关门时不能穿过门洞。

车辆和树木的生成数据现在同时供绘制与碰撞使用；树木使用小树干矩形。车辆后备箱位置也来自同一数据。碰撞移动分步，避免高速越过薄墙。搜索使用耗时动作，受击和移动可取消，完成搜索不直接转移物品。

触摸层记录每个触点。物品按钮在松手后激活，移动超过阈值改为滚动，防止滚动误触；滑轨和内容拖动覆盖所有注册的滚动面板。屏蔽这些操作重复的模拟鼠标点击。独立测试覆盖短点、长拖、滑轨、取消及摇杆多指释放。

新地图按种子生成聚落、道路与连续生态分布，查询树木和车辆使用确定性分块缓存，渲染只处理附近对象。旧存档保留原布局与容器标识；重开才生成新布局。
