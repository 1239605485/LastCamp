# 末日营地第一版实施计划

**Goal:** 根据设计依据第16.1节制作可玩、可保存的一天纵向原型，并导出 Android arm64 测试包。
**Architecture:** Godot 4.7.2 / GDScript。World 作为单一权威状态；物品以实例与所有权维护；两分区共享时钟和营地事件。地图表现、输入、UI 与数据分开。
**Spec:** ../../设计依据_v0.1.md。用户本次明确要求以此文档开始制作，采用建议默认作为第一版实现选择。
