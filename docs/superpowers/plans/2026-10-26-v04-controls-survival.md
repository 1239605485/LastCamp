# v0.4 操作、角色与野外采集实施计划

目标：按用户本轮截图反馈修复角色图集、枪口、物品白边，完善可调触屏与缩放、四项状态条及集中小镇和可采集植物。继续仅交付 Android arm64。

实现：沿用 Godot 4.7.2 工程。UI设置独立保存，不依赖世界存档。角色方向和帧索引独立；枪身与弹道共用枪口坐标。地图v4新增聚落布局，旧v3地图不重排。采集冷却以世界分钟保存，不因读档刷新。

- [x] UI：hud.gd / touch_layout.gd，图标主操作、较大热区、布局编辑、设置持久化、状态条、安全双指缩放；独立触点及滚动回归。
- [x] 角色：actor_pose.gd / world_view.gd，核对Mini源Animation的四向帧，走路只改步伐；持枪锚点与枪口统一，近墙不开穿墙枪。
- [x] 图标：icon_image.gd / art.gd，去除透明边缘邻接的纯白描边，保留内部白色。
- [x] 世界：world_map.gd v4集中聚落、少量独立建筑，增加确定性植物；forage.gd / world.gd / game.gd处理耗时采集、容量、冷却和保存。
- [x] 参考审查：Rogue Survivor本地源码记录适用规则，不导入其完整C#回合制逻辑。
- [x] 验证：新增回归先失败再实现；跑全套、真实引擎截图、仅arm64导出和签名检查。

风险检查：多指按钮与双指缩放冲突；缩小时画面边缘空洞；枪口越墙；采集被打断、背包满、读档重复领取；旧版本地图与容器标识保留。
