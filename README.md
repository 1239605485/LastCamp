# 末日营地 v0.5 · 安卓64位个人自用版

安装 builds/LastCamp-v0.5-arm64.apk。包名 org.lastcamp.survival，版本0.5.0 / versionCode 5，沿用调试签名，仅arm64-v8a。可以覆盖安装；新机制自动补入旧存档，本次不必重开世界。

## 两项实机反馈修复

画面改为按手机宽高比扩展，移除16:9适配造成的左右黑边；安卓启动使用全屏，HUD在安全区域内重新布局，保留场景双指缩放。

按钮裁掉图像透明留白，修正互动图集多读下一帧的问题；图像使用铺满按钮的独立绘制层，底框、编辑框与触摸范围共用尺寸。保持图标比例，大小设置范围56–160，摇杆直径100–190。暂停 → 调整按钮布局，拖动后保存；旧布局设置仍保留，宽屏中按相对位置适配。

## 新机制与操作

点击右侧“工具箱十字”图标进入生存操作。靠近相关物件、设施或同伴，列表会增加对应操作。完整面板暂停世界，确认后恢复并耗时执行；移动和受击取消未完成动作。

| 机制 | 当前玩法 |
|---|---|
| 门窗防守 | 木材2封门/封窗，拆板、破门、打破窗玻璃、靠近窗边后翻越。僵尸会逐步损坏加固与门窗，破门不能重新关上，但可重新封板 |
| 家具推拉 | 靠近柜子打开生存操作，推/拉24单位，拉动时人物一起后退，消耗8体力；不先打包，仍是原家具实例 |
| 同伴指令 | 靠近同伴可下令跟随、守位、附近巡逻、撤到身边、停火/开火。最多一名随行，局部绕障寻路；停火同步到离屏守卫结算 |
| 动态事件 | 第2天08:00无线电预告、10:00出现补给，之后每两天交替补给/求救。地图标记坐标，24游戏小时后失效，必须到场领取；每次只结算一次 |
| 陷阱警报 | 尖刺消耗木材2，响罐消耗零件1。敌人触发后分别伤害/减速或发出警报、吸引附近僵尸；一次性，靠近可清理失效陷阱 |
| 食物保鲜 | 野莓1天、番茄2天、苹果3天、西葫芦4天。接近变质时营养降低，变质不能食用，可从背包或生存操作清理；罐头不腐坏。背包显示状态 |
| 疲劳与睡眠 | 疲劳随时间累积，高疲劳降低移动和体力恢复。可原地休息，营地床位附近可睡眠，睡眠恢复更快；移动、开火或受击结束休息。世界及夜战继续推进 |
| 电池与供电 | 手电夜间耗电；携带电池可更换。营地发电机每份燃油供电120游戏分钟，支持营地灯光。升级一次性补给电池/燃油放在仓库，需先取到身上 |
| 物资交换 | 营地东侧中立商人：2罐头换18发9mm、3零件换电池、5木材换燃油，每日限量，检查物品和负重后同时交换 |
| 天气 | 晴、多云、雨、暴雨按种子与世界时间变化，影响明暗、雨景及人物/僵尸观察距离，室内不画雨线 |

求救事件本版为交付饮水、获得补给和同伴经验；不会突破已有NPC数量上限。发电为固定营地灯组供电，没有铺设线路系统。窗户每栋选一处安全立面开口，翻越是短距离耗时动作。寻路是有范围和节点上限的局部绕障，尚不是全地图复杂路线规划。
