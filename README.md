- 保留已有鲜食变质系统，增加新鲜度存档字段校验。连续射击增加有上限的散布，停火后恢复，准星反馈同步；敌人贴近门窗时不可加固，完成动作时再次检查。
- 参考 `all_alone-main` 的 `Gun.cs` 连射散布恢复和 `BoardedWindow.cs` 的受威胁加固限制，重新用现有二维 GDScript 实现。未拷入其三维场景、C#脚本或素材。

使用相同探索版存档目录和schema 6，新字段可选；旧档载入时初始化空集雨桶列表，不发放材料、不重置地图。请先备份自己的存档。原有自动备份保存机制保留。

```powershell
python tools/check-next.py --godot "你的Godot控制台程序路径.exe"
```

# 末日营地：自由探索 0.6.1

Godot 4.7.2、Android 横屏的单人像素生存原型。游戏以持久化小镇与林区为场景，玩家自行寻找住所、清理房间、搜集物资，并决定何时迁往下一个地区。

当前版本刻意取消固定营地、核心血量、固定时刻返营和每晚强制尸潮。屋子是可以暂住和登记的普通建筑；受到威胁时可以撤离，住所毁坏不会结束世界。

## 启动

电脑：在项目文件夹运行 Godot 后打开 `project.godot`，按 F6/F5。导出后运行 `builds/windows-next/LastCamp-v0.6.1.exe`。安卓 ARM64 安装包输出到 `builds/android/LastCamp-v0.6.1-arm64.apk`；它使用单独的包名 `org.lastcamp.exploration`，可与旧版并存。

新版在独立项目 `next/` 中开发。它使用专属 `LastCamp-FreeExploration-v0.6` 存档目录，不会覆盖原来的守家版存档。0.6 探索版存档继续使用；旧版守家进度目前不自动转换。

## 操作

| 动作 | 电脑 | 安卓 |
|---|---|---|
| 移动 | WASD / 方向键 | 左摇杆 |
| 瞄准与射击 | 鼠标瞄准并左键射击，空格射击 | 右摇杆拖动瞄准并持续开火；开火按钮也可用 |
| 互动 | E | 互动按钮 |
| 背包 | B / Tab | 背包按钮 |
| 区域地图 | M | 地图按钮 |
| 生存操作 | 靠近目标后打开操作列表 | 靠近目标后点生存操作 |
| 武器与物品 | 数字键 / 背包 | 底部六格快捷栏 |
| 暂停 | Esc | 暂停按钮 |

双指缩放场景，单指拖动区域地图。设置中可调整摇杆位置和大小、开启左手模式。完整背包与地图面板暂停世界；开门、搜刮、转移、包扎和旅行等行动会在返回游戏后执行。行动途中移动、受击或失去目标会中断，完成时重新核对距离和物品归属。

## 本版已实现

- 榆树镇与松溪林区两个保存独立状态的地区；地区线索区分听说、发现入口与抵达。地区出口只有走到现场才可旅行；路上遭近距离追击时不能切图。旅行统一推进15分钟。
- 永久保存门窗、搜索结果、地面家具、同伴、敌人与地区容器；搜过的房间不会再次刷新物资。附近场景全模拟，离开的地区休眠保存。
- 普通、快速与破坏型僵尸。看见玩家后追击，听到枪声、奔跑或破窗后调查声源；丢失目标后搜索最后位置再返回游荡。睡眠时周围威胁会唤醒玩家。
- 房门开关、破门、窗户加固、破窗、清除残留玻璃与翻越。清理过的窗可安全翻过；动作中断不重复消耗木板或工具。
- 可在普通床位休息或睡眠，无须登记住所。床位可命名、登记、取消或设为首选恢复点；多个住所和遗物位置保留。死亡时枪械、枪内弹药、枪械配件与快捷物品全部进入唯一遗物容器，玩家在可用住所或安全位置恢复。
- 物品重量及24格背包容量；带配件的枪、两个地区的实际容器、现场转移与空柜子打包。取放物资只在附近进行，家具可携带到其他地区再放下。
- 最多一名同行者；同行指令、倒地救援、床边休养与独立携带枪械/弹药。两个地区的商店与世界事件各自持久保存并且只结算一次。
- 饥饿、口渴、体力、疲劳、流血、手电电池、天气和过期食物。夜间持续探索；床上睡眠最多按四倍推进世界时间，周边威胁同时行动。
- 参考截图的近距离人物比例、道路和环境细节，场景使用末日环境素材包；背包、快捷栏、状态条和按钮使用 PostApocalypse UI；补充包提供食物、医疗品、武器和室内家具贴图。

## 本轮范围

本轮完成文档第16.1节的可玩第一阶段原型。首发地区为小镇和林区，尚未实现其它规划的工业区、城市、完整住宅建造/住所防御、门锁钥匙/撬门、装备耐久、写实弹匣、离屏尸群迁徙、多层建筑、复杂地图传闻搜集及第二阶段长期水食经济。失血、饥渴和负重仍是简化数值；临床恢复、商人配方与资源平衡需继续实玩调整。自动测试和桌面导出不等于安卓真机触控、性能或温升验证。
